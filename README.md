# Kimi Leminaho - Portfolio

En portfolio som var en bra uppgift för JavaScript-ramverks kursen.

Portfolion är byggd i React och visar mina kompetenser, lite information om mig och några av mina projekt.

## Tekniker

- **TypeScript**
- **React**
- **Tailwind**
- **Vite**
- **Git** och **Github**
- **Motion**

## Köra projektet lokalt

```bash
git clone [https://github.com/Prxjec-t/portfolio]
cd portfolio
npm i || npm install
npm run dev
```
